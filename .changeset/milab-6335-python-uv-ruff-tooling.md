MILAB-6335: put the python software on a uv + ruff dev/test setup. All three packages share ONE `software/pyproject.toml` (one uv.lock, one venv, one ruff/pytest/coverage config); each package's runtime pins live in a PEP 735 `[dependency-groups]` entry, and `pnpm software:reqs` compiles each group to that package's `src/requirements.txt` (`uv pip compile --group <pkg> --no-deps`), which is what pl-pkg builds from. No dependency versions changed — requirements.txt is only re-sorted and gains the autogenerated header. The source scripts were ruff-formatted (formatting + import-sort + long-line wraps only; no behavior change). The VBC golden-test bed (previously a local, uncommitted directory) is committed at `software/test-data/vbc-synthetic/`, with one shared `software/conftest.py` providing the fixtures for both packages' tests. Added fast, KDE-free property/example tests (Hypothesis) for the load-bearing math — filter's threshold invariant (always a 6-tuple, never the old None crash) and normalize's round-half-up + zero-drop estimation — alongside the existing golden comparisons, now marked `@pytest.mark.slow`. A new Python Tests CI workflow gates all three packages with ruff (check + format), runs the fast tests on every push and the slow golden comparisons on the merge queue / main, and verifies every requirements.txt is in sync with the shared pyproject.
